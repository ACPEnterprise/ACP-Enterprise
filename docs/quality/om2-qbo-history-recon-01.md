# OM2 QuickBooks history reconciliation

This task qualifies a read-only accounting history projection with synthetic
fixtures. It does not claim protected QBO custody, All County financial
acceptance, OAuth authorization, posting authority, or native admission.

The projection preserves provider object type and identifier, accounting date,
source-reported amount and currency, explicit object relationships, evidence
digest, and unresolved exceptions. Exact replay converges. Changed evidence
under an existing identity and missing relationships are held without payload
projection. Every item remains source-backed and `accepted_as_native` is false.

This contract is intended for permission-scoped historical financial UI
readback while QuickBooks remains authoritative.
