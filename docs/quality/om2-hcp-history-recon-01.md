# OM2 HCP history reconciliation

This task qualifies a provider-neutral, read-only reconciliation contract using
synthetic records only. It does not claim All County source custody, population
acceptance, native admission, or HCP connectivity.

The projection preserves HCP source identifiers, evidence digests, explicit
parent relationships, and communication lineage. Exact replay converges;
changed evidence under one identity and missing parents remain held exceptions.
No relationship is inferred and no source or target write exists in this path.

The resulting deterministic graph is suitable for the existing historical-read
and customer-history UI boundary after protected evidence becomes available.
