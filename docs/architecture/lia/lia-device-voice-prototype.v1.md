# LIA device voice prototype v1

This prototype makes the existing local-device Variant B testable without
selecting a provider or claiming a permanent LIA voice. The LIA voice panel now
lists deterministic local English voices exposed by the browser, allows the
operator to store one reviewed voice URI in that browser only, and previews it
against the same 12-response semantic evaluation corpus used by the voice
harness.

The preference is local presentation state. It is not Company policy, model
admission, biometric ranking, gender inference, or similarity scoring. If the
voice disappears, the existing deterministic local-English fallback remains in
force. Relative rate remains `0.94`, pitch `1`, volume `1`, and the semantic
spoken renderer remains authoritative for what is said.

The source interview remains unavailable in sanctioned ACP custody, so pace,
pause, cadence, inflection, and accent measurements remain
`REFERENCE_MEASUREMENT_PENDING`. The current product target—warm, calm,
confident, professional, conversational, restrained—is not represented as a
measured Lianne profile.

Device review should compare all candidates using Customer, Job, currency,
percentage, time, Payroll blocker, missing evidence, uncertainty, Beacon,
period comparison, Price Book, and employee-safe denial cases. Review
intelligibility, warmth, credibility, natural rhythm, limitation delivery,
numbers, acronyms, and robotic artifacts. Never score similarity to a person.

Variant A remains implemented: the semantic spoken renderer shapes concise,
normal, and detailed responses while preserving material values, applies the
bounded delivery categories, and maps the provider-neutral profile to the
current device controls. Variant B is now directly reviewable on the target
browser. The current stack remains demonstrably limited in cross-device
identity, deterministic pauses, expressiveness/stability controls, and portable
SSML; those constraints justify the already-approved Twelve Hats-owned Variant
C research path, not a commercial provider purchase.
