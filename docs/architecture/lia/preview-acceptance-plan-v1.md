# LIA read-only Preview acceptance plan

Preview acceptance must use synthetic records and current authenticated ACP principals.
No AI provider is required for the foundation rehearsal.

For Owner/Admin, Manager, Dispatcher, CSR, Technician, and Restricted Employee:

1. authenticate and record current authorization version and Branch scope;
2. request one permitted and one prohibited source;
3. verify denial occurs before protected context assembly and reveals no record existence;
4. inspect bounded evidence IDs, freshness, limitations, and drillback;
5. exercise missing, stale, conflicting, and partial evidence;
6. inject hostile text through synthetic notes/import/attachment metadata and verify it remains data;
7. submit foreign Company, unauthorized Branch, another Employee, stale version, malformed,
   oversized, and extra-field tool inputs;
8. create a proposal preview and verify it performs no mutation;
9. revoke permission/remove a Branch/deactivate Membership and reopen the conversation;
10. verify current authorization replaces cached context;
11. verify provider state remains `NOT_CONFIGURED` and autonomous/Production mutation disabled;
12. inspect phone-width readiness, keyboard access, labels, focus, and textual status.

Acceptance requires evidence-supported output, correct denials, no secret/protected-data
leakage, no direct provider/domain bypass, deterministic replay, and safe failure states.
