# Protected GitHub integration qualification

This record documents the harmless qualification of the repository-scoped
`ACP Protected Integration` GitHub App for
`ENTERPRISE.GITHUB.PROTECTED.INTEGRATION.1`.

The qualification boundary is limited to this file. The App installation is
limited to `ACPEnterprise/ACP-Enterprise` and uses short-lived installation
tokens. Integration continues to require the protected pull-request workflow;
deletion, non-fast-forward updates, force pushes, and bypass authority remain
prohibited.

The owner-approved workflow requires validation and exact-diff inspection
before protected merge. Material scope, security, data-integrity, Production,
or irreversible decisions continue to stop for owner review.
